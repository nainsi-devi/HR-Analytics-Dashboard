# HR Analytics Dashboard

## Project Overview

This project focuses on analyzing employee data to understand workforce trends, employee attrition, job roles, satisfaction levels, demographics, and other HR-related metrics.

The data was cleaned and analyzed using **Microsoft Excel**, and an interactive **HR Analytics Dashboard** was created using **Tableau** to present key findings in an easy-to-understand visual format.

## Tools & Technologies

* **Microsoft Excel** – Data cleaning and analysis
* **Tableau** – Data visualization and dashboard development
* **GitHub** – Project documentation and portfolio

## Dataset

The dataset contains **1,470 employee records** and includes information related to:

* Employee demographics

* Monthly Income

* Work-Life Balance
